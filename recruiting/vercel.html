Skills to demonstrate

Decompose and collaborate

Restate the goal, ask about ambiguous behavior, name assumptions, and divide the work into testable slices. Surface a precise blocker instead of going silent.

Build confidently in TypeScript

Be fluent with typed records and unions, `Map` and `Set`, array transforms, dates, Promises, `async`/`await`, error propagation, state updates, and unit tests.

Debug the cause

Reproduce the issue, state a hypothesis, isolate the boundary, fix the root cause, add a regression test, and name the log or trace that would have shortened diagnosis.

Explain production tradeoffs

Discuss APIs, data models, pagination, caching and freshness, rate limiting, idempotency, failure behavior, observability, and rollout at the scale actually requested.

Three-session plan

TypeScript under interview conditions

Complete the event explorer, then Simplify Path and one time-window problem. Redo failed edge cases from a blank editor.

Build and explain

Complete the Next.js feature, deploy it, and record a five-minute walkthrough of requirements, boundaries, tests, compromises, and next steps.

Debug, design, and tell stories

Complete the debugging and design drills, then rehearse the project, blocker, tradeoff, root-cause, and responsible-AI stories.

Live interview operating loop

  1. Clarify: users, inputs, outputs, constraints, errors, and success criteria.
  2. Decompose: name the smallest end-to-end slice and the pieces you will build.
  3. Choose: explain the data model and meaningful tradeoffs.
  4. Build: keep a working path and narrate decisions rather than keystrokes.
  5. Verify: test happy path, minimum input, empty state, tied data, failure path, and boundary times.
  6. Reflect: discuss complexity, production risks, observability, and the next iteration.

Ask the recruiter

  • What stages, durations, and broad competencies are evaluated?
  • Is the coding exercise live, take-home, or proctored?
  • Is it algorithmic, product/frontend, debugging, or a mixture?
  • Which language, framework, editor, and starter repository will be used?
  • Which references, internet access, and AI tools are permitted?
